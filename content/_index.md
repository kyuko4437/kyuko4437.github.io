## 主な作品 — Game

魔女の脳が公開した作品には以下のものがある。

### タンサキ 片道の宇宙探索 {#tansaki}

{{< infobox 題名="タンサキ 片道の宇宙探索" 画像="/img/tansaki.jpg" キャプション="キービジュアル" >}}
ジャンル = 2D探索アドベンチャー
開発元 = [魔女の脳](/majobrain/)
発売日 = 2021年10月26日
対応機種 = [iOS](https://apps.apple.com/jp/app/id1592026391)
価格 = 無料
{{< /infobox >}}

**タンサキ 片道の宇宙探索**（たんさき かたみちのうちゅうたんさく）は、[魔女の脳](/majobrain/)が開発し、iOS 向けに配信されたゲーム。以前はAndroid向けにも配信されていたが、クローズドテストを行えるほど知人がおらずアカウントごと消滅した。

物語の舞台は探求心がエネルギーになる惑星。プレイヤーは惑星出身の飛行士らであり、より多くの探求心を発見し文明を再建するため、片道の探査機に搭乗し未知の宇宙を探索する。

主な登場人格は飛行士、通信士、整備士。

#### ゲームシステム

### まどろみトラベル {#madoromi-travel}

{{< infobox 題名="まどろみトラベル" 画像="/img/madoromi-travel.jpg" キャプション="キャッチコピーは「寝たら即終了の一人旅」" >}}
ジャンル = 選択型シュミレーション
開発元 = [魔女の脳](/majobrain/)
発売日 = 2024年4月26日
対応機種 = [Windows（Steam）](https://store.steampowered.com/app/2821020)
価格 = ¥300
{{< /infobox >}}

**まどろみトラベル**は、[魔女の脳](/majobrain/)が開発し、Steam で配信されたゲーム。
主な登場人格はコノミ、ミモザラ、ミモラ、ミモ。

{{< quote 発言者="Steamストアページより引用" >}}
睡魔に負けず、旅をしよう。
『まどろみトラベル』は旅行好きって程でも無い少女”コノミ”が、海の干潮時に姿を現す「睡眠街」へ赴く旅行を描く、死に覚えローグライクシュミレーションです。睡眠街は旅を阻む「まどろみ」でいっぱい。コノミが旅の途中で寝落ちしないように努めるのがあなたの役目です。
{{< /quote >}}
